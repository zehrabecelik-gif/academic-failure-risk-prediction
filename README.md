# Early Risk Profiling for Academic Failure Using Socio-Academic Indicators

A machine learning project developed to identify students at risk of academic failure using socio-academic indicators.

## Project Overview

The goal of this project was to explore how machine learning techniques can be used for early identification of academically at-risk students. The project covers the full analytical workflow from data preprocessing to model evaluation and comparison.

## Data Preprocessing

The dataset was prepared for machine learning through:

- Missing value handling
- Categorical variable encoding
- Feature standardization
- Data preparation for classification models

## Machine Learning Models

Three classification algorithms were implemented and compared:

- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)

Principal Component Analysis (PCA) was also applied to examine dimensionality reduction and its impact on model performance.

## Model Evaluation

Model performance was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

Logistic Regression achieved **92% accuracy** and provided the strongest overall performance among the tested models.
